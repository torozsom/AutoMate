# wwwroot

Static CSS, JavaScript, and browser-facing assets.

First-party JavaScript functions and callbacks use multiline JSDoc with typed parameters, return/completion semantics
and supported escaping failures. Document listener, observer and terminal disposal where callers own those lifetimes.
Vendored Bootstrap files retain their upstream documentation, minification and license headers.

## Boundary

Keep presentation behavior here. Components, hubs, routes, and services use Application contracts; concrete
Infrastructure types are registered only in Web/Configs.
